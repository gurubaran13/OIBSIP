# OASIS INFOBYTE - Java Development Internship

This repository contains the three Java tasks I completed during my Java Development Internship at OASIS INFOBYTE. I created these projects to practise Java programming and understand how it can be used to build different applications.

## Tasks

### Task 1: Online Reservation System

A simple reservation application for managing train reservations.

**Main features**
- User login
- Train reservation and booking details
- Ticket cancellation
- Stores reservation data using SQLite

**Technologies used:** Java, Java Swing, JDBC, SQLite

### Task 2: Number Guessing Game

A small Java game where the player tries to guess a randomly generated number. It is a useful way to practise basic programming logic and user input.

**Concepts practised**
- Random number generation
- Conditional statements and loops
- Taking user input
- Checking guesses and displaying results

**Technology used:** Java

### Task 3: ATM Interface

A Java Swing application that simulates some common ATM operations through a graphical interface.

**Main features**
- Login using user ID and PIN
- View account balance
- Deposit and withdraw money
- Transfer money
- View transaction history

**Technologies used:** Java, Java Swing

## How to Run

1. Install Java JDK on your computer.
2. Clone or download this repository.
3. Open the `Java Development` folder in your preferred Java IDE, such as VS Code or Eclipse.
4. Open the task folder you want to try.
5. Run the main Java class for that project.

For the Online Reservation System, make sure the required SQLite JDBC dependency is available before running the application. If the project uses Maven, open the folder containing `pom.xml` and let Maven download the dependencies.
